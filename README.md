# Датчик замер: интерактивная лаборатория на WISDM

Это **отдельная публичная публикационная копия**, а не исходный исследовательский репозиторий.

**[Открыть опубликованную версию](https://kr13t1.github.io/ts-reliability-habr-demo/)**. Ветка новой версии добавляет четыре шага и раскрываемый расширенный режим.

На странице можно сравнить реальную запись телефонного акселерометра WISDM subject 1600 до/после **контролируемого искусственного** замирания оси X, посмотреть назначенную маску Z и предсказание простого offline detector (L=3, точное равенство), а также контрольные случаи без инъекции. Страница не диагностирует телефон, не обучает модель и не пересчитывает детектор в браузере.

## Что можно проверить

| Сценарий | TP | FP | FN | TN |
|---|---:|---:|---:|---:|
| Walking без искусственного сбоя | 0 | 0 | 0 | 3574 |
| Walking, freeze X на [1191,2382) | 1191 | 1 | 0 | 2382 |
| Standing без искусственного сбоя | 0 | 0 | 0 | 3572 |

Это **одна искусственная неисправность и один человек**, а не проверка качества на независимых устройствах. Промах на отсчёте 1190 — ошибка относительно назначенной маски, не свидетельство реального отказа.

Числовой payload соответствует audited snapshot в приватном PR #30. Пошаговый интерфейс этой ветки изменён и требует отдельной проверки 05; публичный сайт на main до слияния показывает прежнюю версию. SHA-256 `index.html`:

## Офлайн-запуск

Скачайте `index.html` и откройте его двойным щелчком в браузере. Никакого сервера, API-ключа, JavaScript-пакетов и Интернета не требуется.

## Воспроизводимая сборка HTML

```bash
python build_demo.py --check
python -m unittest discover -p 'test_*.py' -v
```

`build_demo.py` восстанавливает исходный `index.html` **побайтно** из `source/template.html` и `source/payload.json` и независимо проверяет маски и сводные числа. Это **snapshot-to-HTML**, а не оригинальный исторический **raw WISDM-to-HTML** builder. Сохранённые числовые ряды сверялись в независимом аудите 05 с raw-member WISDM, но здесь не включены сырой TXT, закрытые исследовательские файлы и полный G2.
